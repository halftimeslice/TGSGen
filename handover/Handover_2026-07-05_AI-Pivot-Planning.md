3. **End goal: 100% correct generation, no user editing required.** Claude was honest that literal 100% can't be guaranteed; the accuracy recipe is: exact inputs → automatic checker that validates every number against TCAWS tables and sends failures back to the AI to fix before the user sees them → test library of real approved TGSs to score against.
